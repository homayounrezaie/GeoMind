## What This Is

GeoMind is a compact roadmap for understanding the modern geospatial AI stack. It is designed for:

| Audience | Use case |
| --- | --- |
| Newcomers | Find a practical starting path through geospatial AI concepts. |
| Practitioners | Use it as a reference for data types, model families, tasks, tools, and standards. |
| Researchers | Spot gaps, combinations, and underexplored links between methods and applications. |

## Roadmap Layers

| Layer | Covers |
| --- | --- |
| Data | Sensors, platforms, formats, indexing, embeddings, and catalogs. |
| Learning paradigms | Supervised, self-supervised, weakly supervised, active, transfer, and multimodal learning. |
| Model types | Classical ML, deep learning, foundation models, segmentation models, transformers, and geospatial encoders. |
| Key techniques | Fusion, retrieval, change detection, temporal modeling, uncertainty, compression, and evaluation metrics. |
| Remote sensing tasks | Classification, segmentation, detection, forecasting, preprocessing, and engineering workflows. |
| Companies | Products, services, infrastructure providers, and applied geospatial AI teams. |
| Datasets and benchmarks | Public datasets, benchmark tasks, leaderboards, and evaluation resources. |
| Stack and infrastructure | GEE, AWS, Azure, PyTorch, GDAL, Rasterio, MLflow, W&B, Docker, TensorRT, PostGIS, and pgvector. |
| Standards | STAC, COG, OGC APIs, GeoParquet, and cloud-native geospatial formats. |
