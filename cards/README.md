# GeoMind Cards

This folder contains published card pages and reusable card templates.

## Structure

- `models/` contains model card pages.
- `datasets/` contains dataset card pages.
- `benchmarks/` contains benchmark card pages.
- `papers/` contains paper card pages.
- `_templates/` contains starter YAML files for structured card data.

Use lowercase, hyphenated filenames that match the card slug, for example:

```text
cards/models/alphaearth.html
cards/datasets/sen12ms.html
cards/benchmarks/bigearthnet.html
cards/papers/satmae.html
```

The `data/` folder remains the published JSON used by tables and search.
