Privacy

GeoMind is designed as a simple public reference site. This page explains the kinds of information a GeoMind website may handle and how it should be treated.

GeoMind is a public reference site. If you submit information through a form, GeoMind should use it only for the purpose shown on that form. External papers, datasets, and model links follow their own privacy practices.
