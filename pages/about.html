About GeoMind

GeoMind is a structured hub for Geospatial AI. It helps researchers, engineers, and practitioners follow important models, datasets, benchmarks, and papers in one clean place.

Vision

GeoMind's vision is to make Geospatial AI easier to navigate. The catalog keeps models, datasets, benchmarks, and papers in one consistent structure so people can quickly see what exists, compare related work, and move from a summary to the original source.

Where the data comes from

GeoMind is built from public research and project sources: papers, official project pages, benchmark pages, GitHub repositories, Hugging Face model cards, and curated raw exports. Raw inputs are cleaned before publication, and the site uses the committed table and JSON data as its published catalog layer.
