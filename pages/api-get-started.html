GeoMind API

Get started

Fetch GeoAI data over plain HTTP — no keys, no SDK, no rate limits.

Documentation Index

Fetch the complete endpoint index at /api/index.json. Use it to discover available datasets and record counts before loading a full endpoint.

Set the base URL

Every endpoint is a static JSON file served under one base URL. There is nothing to install — fetch it from the browser, a script, or the command line.

const BASE = 'https://homayounrezaie.github.io/GeoMind/api/';

const index = await fetch(BASE + 'index.json').then(r => r.json());
console.log(index.endpoints);
import requests

BASE = 'https://homayounrezaie.github.io/GeoMind/api/'
index = requests.get(BASE + 'index.json').json()
print(index['endpoints'])
curl https://homayounrezaie.github.io/GeoMind/api/index.json
Authentication

There is no authentication. GeoMind exposes versioned public data snapshots over GitHub Pages — no API key, no auth header, and no server-side rate limit. Treat each file as a read-only snapshot that refreshes when the site is rebuilt.

Fetch an endpoint

Each endpoint returns a JSON array of records. Load one and read the first row to see its shape.

const res = await fetch('https://homayounrezaie.github.io/GeoMind/api/papers.json');
const papers = await res.json();

console.log(papers.length); // 18229
console.log(papers[0]);
import requests

papers = requests.get('https://homayounrezaie.github.io/GeoMind/api/papers.json').json()
print(len(papers))  # 18229
print(papers[0])
curl https://homayounrezaie.github.io/GeoMind/api/papers.json

Browse the request and a live sample response for every endpoint in the Endpoints reference.

Discover endpoints

The index lists every endpoint with its path and record count, so you can size a request before loading a full file.

const index = await fetch('https://homayounrezaie.github.io/GeoMind/api/index.json')
  .then(r => r.json());

for (const ep of index.endpoints) {
  console.log(ep.name, ep.count, ep.path);
}
import requests

index = requests.get('https://homayounrezaie.github.io/GeoMind/api/index.json').json()
for ep in index['endpoints']:
    print(ep['name'], ep['count'], ep['path'])
curl https://homayounrezaie.github.io/GeoMind/api/index.json
