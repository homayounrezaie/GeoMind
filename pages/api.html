Get started

GeoMind currently exposes static JSON over GitHub Pages. There is no API key, auth header, or server-side rate limit. Treat the files as versioned public data snapshots that refresh when the site is rebuilt.

JavaScript
const base = 'https://homayounrezaie.github.io/GeoMind/api/';
const index = await fetch(`${base}index.json`).then(res => res.json());
const papers = await fetch(`${base}papers.json`).then(res => res.json());

console.log(index.endpoints);
console.log(papers[0]);

Endpoints

Each endpoint returns a JSON array except index.json, which returns metadata for discovery.

papersResearch papers with citations, links, abstracts, venues, and source metadata. modelsFoundation model candidates and references for geospatial AI. datasetsGeospatial and remote-sensing datasets with tags and usage signals. companiesOrganizations across geospatial, EO, GIS, analytics, and UAV markets. benchmarksBenchmark rows connecting papers, tasks, datasets, metrics, and scores. tasksGeoAI task names and categories. metricsEvaluation metrics and metric families. techniquesMethods, algorithms, and learning techniques.

Schema

Records keep source field names so the API remains close to the underlying catalog. Empty CSV values are omitted, numeric fields are typed as numbers, boolean flags are typed as booleans, and common delimited fields are converted to arrays.
