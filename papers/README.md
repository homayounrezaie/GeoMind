## Data Files

- [`papers.csv`](papers.csv) is the editable source of truth.
- [`titles-and-links.csv`](titles-and-links.csv) contains only the fields requested for import elsewhere.
- [`titles-and-links.md`](titles-and-links.md) is the title/link-only reading list.
- [`papers.json`](papers.json) is convenient for scripts and UI work.
- [`conferences.yml`](conferences.yml) and [`keywords.yml`](keywords.yml) document the collection scope.

## Notes

- The 2026 coverage is partial because some conference proceedings may not be finalized yet.
- Links prefer DOI landing pages, then publisher/conference pages, then OpenAlex records.
- The collector stores metadata only and does not download PDFs.
